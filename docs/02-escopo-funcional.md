# Escopo Funcional do VolunHub

## Funcionalidades do voluntario
- Consultar projetos disponiveis sem login.
- Buscar e filtrar projetos por cidade, estado, categoria, tipo de participacao, status e disponibilidade de vagas.
- Criar conta como voluntario.
- Fazer login com credenciais.
- Inscrever-se em projetos.
- Visualizar suas inscricoes.
- Acompanhar historico de participacao.
- Atualizar o proprio perfil e dados de contato.

## Funcionalidades da organizacao
- Criar conta como organizacao.
- Fazer login com credenciais.
- Cadastrar projetos sociais.
- Editar projetos existentes.
- Excluir projetos quando necessario.
- Selecionar categorias de projetos previamente cadastradas no sistema.
- Visualizar voluntarios inscritos em cada projeto.
- Atualizar status das inscricoes.
- Consultar lista de projetos publicados.

## Funcionalidades publicas sem login
- Visualizar lista de projetos disponiveis.
- Filtrar projetos por cidade, estado, categoria, tipo de participacao, status e disponibilidade.
- Ler detalhes basicos dos projetos.

## Funcionalidades administrativas
- Neste escopo inicial nao ha modulo administrativo separado.
- Categorias serao previamente cadastradas no banco para selecao pelas organizacoes.
- O foco e manter o sistema simples e coerente com o escopo de um projeto de ADS.
