# Escopo Funcional do VolunHub

## Funcionalidades do voluntário
- Consultar projetos disponíveis sem login.
- Buscar e filtrar projetos por localização, categoria, status e disponibilidade de vagas.
- Criar conta como voluntário.
- Fazer login com credenciais.
- Inscrever-se em projetos.
- Visualizar suas inscrições.
- Acompanhar histórico de participação.
- Atualizar o próprio perfil e dados de contato.

## Funcionalidades da organização
- Criar conta como organização.
- Fazer login com credenciais.
- Cadastrar projetos sociais.
- Editar projetos existentes.
- Excluir projetos quando necessário.
- Visualizar voluntários inscritos em cada projeto.
- Atualizar status das inscrições.
- Consultar lista de projetos publicados.

## Funcionalidades públicas sem login
- Visualizar lista de projetos disponíveis.
- Filtrar projetos por localização, categoria, status e disponibilidade.
- Ler detalhes básicos dos projetos.

## Funcionalidades administrativas
- Neste escopo inicial não há módulo administrativo separado.
- A gestão do sistema será realizada por perfis de organização e voluntário.
- O foco é manter o sistema simples e coerente com o escopo de um projeto de ADS.
