# Requisitos Funcionais do VolunHub

RF01 - O sistema deve permitir cadastro de usuários como voluntário.
RF02 - O sistema deve permitir cadastro de usuários como organização.
RF03 - O sistema deve permitir login de usuários autenticados.
RF04 - O sistema deve permitir logout seguro.
RF05 - O sistema deve permitir que organizações cadastrem projetos.
RF06 - O sistema deve permitir que organizações editem projetos.
RF07 - O sistema deve permitir que organizações excluam projetos.
RF08 - O sistema deve permitir que organizações visualizem voluntários inscritos.
RF09 - O sistema deve permitir que organizações atualizem o status de inscrições.
RF10 - O sistema deve permitir que voluntários consultem projetos disponíveis sem login.
RF11 - O sistema deve permitir que voluntários busquem e filtrem projetos.
RF12 - O sistema deve permitir que voluntários se inscrevam em projetos.
RF13 - O sistema deve permitir que voluntários visualizem suas inscrições.
RF14 - O sistema deve permitir que voluntários acompanhem o histórico de participação.
RF15 - O sistema deve registrar categorias de projetos.
RF16 - O sistema deve armazenar histórico de participação dos voluntários.
RF17 - O sistema deve manter autenticação JWT para rotas protegidas.
RF18 - O sistema deve fornecer endpoints REST para todas as operações previstas.
RF19 - O sistema deve permitir filtros de busca por cidade, estado, categoria, status, vagas e outros critérios.
RF20 - O sistema deve permitir que projetos ATIVOS sejam exibidos por padrão nas buscas.
